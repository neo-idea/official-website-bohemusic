# Bohe Music official website

Static, dependency-free production site for 薄荷音乐.

- Canonical home: `https://bohemusic.zpad.app/`
- Privacy: `https://bohemusic.zpad.app/privacy`
- Terms: `https://bohemusic.zpad.app/terms`
- FAQ: `https://bohemusic.zpad.app/faq`
- Remote force-update config: `https://bohemusic.zpad.app/config/version.json`

Deploy through the monorepo publish workflow to `neo-idea/official-website-bohemusic`.
The `CNAME` must remain `bohemusic.zpad.app`.
